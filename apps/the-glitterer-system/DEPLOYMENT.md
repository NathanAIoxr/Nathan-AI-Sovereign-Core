# Deployment contract

The functional browser UI prototype is available as `glitterer-build/index.html` in the generated build artifact; the source-controlled shared core and tests are under `src/` and `test/`. Run `npm test` before deployment. Deploy only to a verified authorized Pages project or new approved target. Do not overwrite unrelated Pages projects. All inspection is read-only and local. The game cards are catalog entries, not playable games. There is no active antivirus, backend, telemetry collection, or enterprise service deployment.
