# Diné Heritage + Pumpkin Patch independent product suite
Source preservation: see DINE_NEW_MEXICO_EDUCATION_AGRICULTURE_EXPANSION.md and earlier source archives. No existing app overwritten.

## Modules (each independently opt-in)
- DIN-EDU: Diné history, Dinétah, the Long Walk, Bosque Redondo, 1868 Treaty, sovereignty, modern communities and Diné Bizaad
- DIN-FARM: New Mexico harvest sourcing, grower interviews, water, soil, farm-to-church delivery, verified origin
- DIN-COOK: Diné with Pumpkins, 101 Lost Pumpkin Recipes, Three Sisters, CPT (Chestnuts/Pumpkin/Potatoes), congregation cookbooks
- DIN-KIDS: children's reading, coloring, gardening, classroom packs, QR activities, age-specific history
- DIN-GAME: independent harvest games, gardening challenges, Sorting Hats/Hatettes/Huffettes and Scramble
- DIN-STORE: bulk truck drops, POD books, garden kits, seeds, donation and fundraiser tiers
- DIN-MEDIA: approved interviews, oral histories, videos, educational timeline, permissions and contributor compensation
- DIN-ATLAS: Dinétah geography and research with source/interpretation separation, directional rotation as user hypothesis only
- DIN-WHITE-LABEL: optional licensed church/nonprofit branding without merging independent engines

## Production workflow
Draft -> source check -> Diné community review where appropriate -> rights clearance -> pricing and split approval -> publish -> correction/withdrawal. Default unpublished. Do not infer endorsement or supplier provenance from user report alone.
