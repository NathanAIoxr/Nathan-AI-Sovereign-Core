# Sovereignty OS — Diné Living Universe & Tabor Earth

The local Python and SQLite build preserves the supplied **Bedrock to Vine** framework, `1 - 1 = 0`, `1 + 1 = 2`, and the author's **Divine → The Vine** wording. The [original Markdown](Pasted-markdown-source.md) remains byte-for-byte intact. The [seed](dine_seed.json) contains every data record recovered from its split Python blocks.

Run with Python 3.10 or later using the standard library. Keep the Python, Markdown, JSON, and SQL files in the same directory.

```sh
python sovereignty_os_dine_universe.py
python sovereignty_os_dine_universe.py --db sovereignty.sqlite --section submerged_lands
```

The default prints a full JSON snapshot. With `--db`, the snapshot is also persisted to a local SQLite file. The [shared schema](001_bedrock.sql) runs on SQLite and Cloudflare D1 with an additive import keyed to the upload's SHA-256. A repeat import preserves existing rows.
