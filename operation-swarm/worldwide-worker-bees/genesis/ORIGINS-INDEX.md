# ORIGINS INDEX — Tabor World evolutionary metaphors

This is a **taxonomy of conceptual analogies**, not a scientific claim that cosmology, theology and biological evolution are interchangeable.

| Origin metaphor | Engineering interpretation | Limits |
|---|---|---|
| Big Bang / seed expansion | bootstrap a bounded set of jobs from one configuration | no 0-byte program can contain arbitrary information |
| Creation / template and breath | clone a versioned manifest and assign a distinct identity | no biological life or consciousness is created |
| Mitosis | copy approved capabilities into an inert child manifest | no live worker spawned automatically |
| Crossover | combine two parents' approved skill sets | no automatic merging of executable code or model weights |
| Mutation | generate a sandbox variant for evaluation | no unsupervised production self-modification |
| Ancestral apprenticeship | provenance-linked examples, mentoring, tests | no claim that all cultures used the same practices |

## Family scope
The user's 163 Worker Bot Families remain an existing **target catalog** to import and reconcile by original IDs, not 163 invented rows. The 12 historical machine designs and 24 mythological roles are separate branches. Parent and child references can cross branches when explicitly approved.

## Exam protocol
Ten tests: identity, lineage, generation, inert state, permissions, skills, provenance, generation bound, budget, no runtime execution. Graduation additionally requires operator approval. Failed children stay archived as sandbox records.

## External projects
DGM, evolutionary-model-merge, EvoAgentX, ADAS and Voyager are *candidate adapters*. Their exact APIs, licenses and behavior require upstream verification before installation. Dynamic bundling alone is not permission to deploy self-propagating workers.

## Status
Executable pure TypeScript logic and D1 schema are committed separately in this directory. No Cloudflare deployment, model training, live spawning, or production activation is implied.
