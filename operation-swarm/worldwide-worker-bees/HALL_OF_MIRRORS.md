## Preserve the paradox; distinguish epistemic status
This engine explores both real and unreal models without treating imagination, simulation, metaphor or a reversed string as verified external reality. It never alters the original source.

## Perspective axes
- Grounded / Ungrounded: evidence-backed vs speculative or imaginative
- Left-to-right / Right-to-left: reading order and directional traversal
- Up-to-down / Down-to-up: top-down decomposition vs bottom-up emergence
- Forward / Backward: chronological progression vs reverse causality inspection (not a claim that causality reverses)
- Mirror A / Mirror B / Other sides / No mirror: original, transformed, rotated, and untransformed views
- Real / Not real / Both-as-models / Undetermined: evidence classification, not automatic factual assertion

## Contract
Every transformation records source ID, transform ID, parameters, output, reversibility, confidence/evidence status, hash, and timestamp. Original source immutable. Derived outputs are separate records.
