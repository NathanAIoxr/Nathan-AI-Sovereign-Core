## Fusion One: ASTROLABE + BRONZE URN
- Intake categories: build proposals, integrity reports, safety incidents, speculative research.
- Each submission receives an opaque ID, creation time, optional geographic/time coordinates, evidence status and retention policy.
- Privacy: anonymous submissions allowed where legally appropriate; avoid collecting unnecessary identifiers; abuse controls and consent.
- Indexed archive: provenance links and searchable time/space dimensions. Do not promise absolute anonymity or perfect archival durability.

## Fusion Two: TURING + TESLA
- Turing: local deterministic tape machine and bounded reaction-diffusion simulation.
- Tesla: event-triggered notifications and opt-in authenticated peer transport.
- Genesis: only simulated child genomes until quota, permission and verification gates pass.
- 1,382-node 4T Clover is a model configuration, not a deployed node count.
- No automatic propagation to third-party machines or networks.

## Preservation
Keep the user's twelve original descriptions verbatim in source records when available. All derived interpretations live in separate files. Preserve grounded, ungrounded, mirrored and reversed views as labeled transformations.

## Test gates
- determinism for the same seed and inputs
- provenance and lineage integrity
- permission boundaries and no inherited secrets
- bounded resource consumption
- clear distinction between simulated and measured physical behavior

Status: architecture design. No physical machines, self-replicating nodes, or production Cloudflare services are claimed.
