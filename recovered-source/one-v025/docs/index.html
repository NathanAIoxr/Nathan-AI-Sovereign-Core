Three places to play

  • THE 33: choose a historical trial, then classic practice or a guardian duel. Match tiles toward the trial objective; guardian mode also requires defeating the opponent. Full rules and all 33 stage guides.
  • Rootkeep: complete or skip the three-move tutorial, collect resources, choose a team and launch an expedition. Use earned rewards to train and upgrade. Combat, heroes, resources and replay rules.
  • A–Z Studio: score 1,200 within 30 accepted moves. Four- and five-runs create powers. Open the inspector to explore the 52 engineering layers.

Keep your progress

Each game saves separately in this browser. Use its JSON export before clearing browser data or moving to another device. Import that JSON in the same game to continue. A game’s recovery control restores its previous validated autosave.

Keep using the same browser and local address. Changing the host, port or browser creates a different storage space. Organizing these files has kept the existing game paths and save identifiers.

Run the complete package

Extract PRIVATE_ONE_v025.zip. From that extracted folder run:

python3 -m http.server 8002 --bind 127.0.0.1

Open http://127.0.0.1:8002/. Start with index.html or START_HERE.html. The three exported standalone HTML files embed their game scripts; the full package also includes ONE, the Library and all linked documentation.
