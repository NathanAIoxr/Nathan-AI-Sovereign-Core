Everything stays private in v025. Play is free; rewards are earned. Progress is saved in the browser and can be exported as JSON from each game.

Run from this folder:

```sh
python3 -m http.server 8002 --bind 127.0.0.1
```

Open `http://127.0.0.1:8002/`. Keep the same address to retain access to browser saves.

Edit source here, not in generated releases. Build with `python3 build_private_v025.py`. The sibling `exports/` folder contains the latest complete browsable release, three standalone games, `PRIVATE_ONE_v025.zip` and its SHA-256 checksum. Earlier packages stay in `../history/`.
