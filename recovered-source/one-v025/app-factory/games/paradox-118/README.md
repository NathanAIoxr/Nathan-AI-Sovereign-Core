# 🚂oOo🚂 THE 118 LINE — Great Parade of Paradoxes

Playable, static browser-game prototype built in the existing TABOR 1–2–3 Factory. Product ID: T123-PARADOX-118-001.

## Gameplay
1. Open index.html in a browser and select any of the 118 exact canon character identities.
2. Solve ABOVE C (name reading), BELOW C (literal middle-word reversal) and THE MIDDLE C (fair, protective decisions).
3. Completing one figure in each of 13 groups earns all collection keys and completes the Grand Parade; completing all 118 spotlights earns Master Collector.
4. Data and save remain in the local browser with explicit JSON export/import. No network, signup, paid content or ads.
