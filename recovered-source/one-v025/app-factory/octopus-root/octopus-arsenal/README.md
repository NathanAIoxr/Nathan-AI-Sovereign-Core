## What is actually playable

This is an original, mobile-first, zero-runtime-dependency browser **video game plus progressive web app (PWA)**. The game and app live under one product so the player can switch between action, equations and Root graph operations without logging in.

Launch: [Play Octopus Arsenal](./index.html).

The game is a circular arena-defense campaign with **five themed regions and fifteen waves**, including five boss encounters, against fictional rift drones. The sanctuary represents innocence; no human enemies are depicted. Eight selectable tentacles have fictional powers, cooldowns, energy budgets and levels. Select with keys 1–8, click/tap the arena to aim and fire, press Space for nearest threat, or use optional auto-defense. Press P to pause. Normal game progress and upgrades are browser-local; export/import is explicit. No monetization, advertising, external telemetry, store accounts, in-app purchase, or user profiling.

## Companion app: six integrated screens

1. **Arena:** responsive HTML canvas game, 8 quick-select powers, HUD, waves, boss encounters, pause and optional auto-defense.
2. **Arsenal:** power descriptions and original-phrase formula cards; equip a power for immediate play.
3. **Formula Lab:** interactive mathematical forward/backward challenges using the actual existing [Sovereign Continuum engine](../sovereign-continuum/engine.js). There are 25 runnable models; a first successful calibration can grant +4 in-game Root tokens **once per unique model**. The target is generated deterministically from a valid model input, not faked.
4. **Root Codex:** 25 runnable equations and six documented Python-only deep-root experiments, including assumptions and limitations; search and filter by the five original families.
5. **Workshop:** capped five-level upgrades, earned tokens, personal browser-local records, explicit JSON export/import and reset. No purchasing.
6. **Root Link:** view the actual local Root node/link/review counts, and explicitly **graft** the Continuum's existing 31 formula nodes into the separately persisted Octopus ROOT. The underlying Root engine checks IDs, duplicates and link rules.

The original graphic concept's neon space/tentacle visual direction is translated into **procedural canvas art** and CSS. The poster image and third-party entertainment properties are not embedded in the public code; no outside artistic asset is required.

## Integration and preservation

This product uses the existing [Octopus Root engine](../engine.js) and [Sovereign Continuum engine](../sovereign-continuum/engine.js) directly. The game has a **separate career storage key**; it never rewrites an existing Root document on ordinary gameplay. Grafting is opt-in and idempotent. A browser save is not a server backup; export your game save and Root JSON separately. The Crumb Reaper review bin remains recoverable and unchanged. Neither other branches nor the original poster file are deleted.

## Offline and installation

The manifest, icon and scoped service worker provide offline-capable assets after they have been loaded and cached successfully. The service worker caches only listed game/Root/Continuum assets; it does not intercept external APIs or unrelated Factory pages. Actual offline mobile usage and install behavior should be field-tested on each device/browser. On mobile use the browser's Add to Home Screen / Install App menu. **This is not a signed iOS or Android store application.** Converting it to a distributable native shell will require platform build, signing, store disclosures and review.
