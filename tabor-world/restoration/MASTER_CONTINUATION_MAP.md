## Full-fidelity rules

- Every original game remains its own game; every book its own book; every app its own app; every website its own website. Shared engines are dependencies, not replacements.
- All 182 named registry items are children of these workstreams or independent siblings. Add missing items without deleting or renaming existing items.
- Agent assignments are build specifications until verified by execution receipts; the continuation tag is a standing roadmap designation, not proof that an unattended agent is running.
- Hardware schematics remain in the engineering roadmap with CPU/GPU/ASIC, power, thermal, networking, storage, mechanical and software layers separately identified.
- Reconcile GitHub files, Cloudflare deployments, D1 state, historical project records, and test results before each build cycle.
- Build stages: **CATALOG → SPEC → CODE → TEST → DEPLOY → VERIFY → OPERATE → EXPAND**. Never conflate them.
- Keep budgets, destructive actions, credential changes, public publishing and external outreach behind explicit operator approval.
- Preserve project provenance, protect innocence and consent, and distinguish research claims from verified evidence.
