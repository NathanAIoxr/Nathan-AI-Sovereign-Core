NATHAN AI Compute Cluster: Terraform bootstrap for up to 64 DigitalOcean Linux nodes. Defaults to zero nodes to prevent unexpected billing. Requires an authorized DigitalOcean account, API token, SSH key fingerprints, cost review, and terraform apply. Cloud-init installs a recurring local hardware health check. Cloudflare heartbeat reporting requires installing the existing tabor-world/infrastructure/fleet/agent.py and securely setting FLEET_TOKEN. This module does not yet provision hardware or perform cryptocurrency mining. Never commit tokens or terraform state.
