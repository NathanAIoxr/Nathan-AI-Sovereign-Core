# Nathan AI Fleet Runtime

Every scheduled invocation executes bounded, read-only audit tasks for the 64 registered bot/agent pairs and records D1 receipts. No permanent process, bare-metal provisioning, cryptocurrency mining, quantum compute or externally acting agents are implied. Cron is configured independently on Cloudflare. Results are observational and scoped to existing D1 data. This module does not execute arbitrary code or access third-party credentials.
