# Tabor World · 101 Hands-On Learning Methods

[Open Tabor World](https://tabor-world.nathantaboract.workers.dev/learning-methods/) or [open Tabor Academy](https://tabor-bridge.nathantaboract.workers.dev/tabor-academy/institution/learning-methods/). Each entry point renders the same numbered methods and links to its counterpart. The Tabor World directory also links to the Nine Pillars, Comparative Civics, and the Gateway, Monroe, and Redstone archive.

The original text, activity adaptations, data builder, and route handler are in [the Academy learning-methods directory](../../app-factory/tabor-academy/institution/learning-methods/). Activity checkmarks are kept on the learner's device. Source material is available verbatim at `/learning-methods/source.txt`.

`node build.mjs <current-tabor-world-worker.mjs>` assembles the updated World module against the current Worker. Use the existing `tabor-world` deployment and verify the destination catalog, the collection, and a numbered method.
