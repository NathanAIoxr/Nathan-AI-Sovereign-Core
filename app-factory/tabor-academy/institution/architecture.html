Conductor blueprint

  1. Set the foundation. Read the Academy motto and all four supplied prompts. Carry Motto, Heart, Soul, Shadow, Spirit, Nothing, Everything, and Protecting The One / One Family as Nathan’s terms.
  2. Capture the record. Save the original text and its source location, author, date if known, and version. Keep classification, notes, and corrections in linked records. Store a checksum to detect changes to the original.
  3. Trace backward, then build forward. Follow each quotation or claim back to its source. If two versions conflict, keep both and record their locations and wording. Mark what is verified, unresolved, or an interpretation before building the index.
  4. Protect The One. Set access per record. Make public sources discoverable. Keep private family and personal records limited to the people authorized to see them. Give any public summary only the details cleared for that audience.
  5. Route through the Master Conductor. Personal Memory holds the source. Personal Intelligence checks the source, access, and claim status, then routes a draft to the Library of Tabor or holds it for review. Record the source IDs, decision, reason, and review status for each output.
