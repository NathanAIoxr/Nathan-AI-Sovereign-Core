# Nathan AI 🚀 — Independent Website Universe

The public network at \`app-factory/sites/\` adds nine independently named, accessible, responsive public-safe browser websites to the existing Nathan AI / TABOR ROOT / TABOR 1-2-3 FACTORY / ONE system.

| FIND THE TABOR | \`/sites/find-the-tabor/\` | Source-first genealogy and historical research planning |
| WORDS & LIBRARY | \`/sites/words-library/\` | Book, language and source record studio |

The primary network is \`/sites/\`. It also indexes the 101 earlier public page routes from the existing Nathan AI launchpad and optionally loads only the existing published, nonsensitive concept metadata from \`../products.json\`.

Every studio is a functional, local-only browser tool with working-plan generation, copy, JSON download/restore and printing. No forms submit data, create real accounts, send texts, enroll volunteers, manufacture toys, collect donations or access private original bytes. The personal source-text field is separate from derived planning steps, and no automatic correction occurs.

## Source preservation and status

Original public apps remain in their own paths. The new \`sites/\` folders are additive public gateways, not verbatim restorations of original privately held Next.js / Expo / native projects. The previous 36-tier Christmas Toy Drive prototype and operational backend source remain private and are not deployed or falsely represented by these pages. Unverified custom domain ownership, nonprofit status, transaction capability or private identities are not asserted.

For local development, start a static server from the repository root, e.g. \`python3 -m http.server 8000\`. The pages work directly at \`http://localhost:8000/app-factory/sites/\`; public concept loading requires the same-origin static server.
