# Recovered original artwork — 6.2

This build reuses existing project artwork rather than generating replacement cats.
The four PNG masters are unchanged recovered originals. `scripts/generate_art.py`
extracts the existing illustrated characters/scenes and packages the asset catalog.
No painting, coat recoloring, synthetic inverse cat, or network request occurs.

Stewart and Finn are mapped from the names printed in the original game showcase:
Stewart left, Mr. Finn right. Champ and Ace use the labeled original book artwork.
The home portraits, campaign, playroom, family screens, and icon share those sources.
The workshop viewport excludes its retired South Paw sign; the app uses
**Mrs Clause Cat’s Workshop** throughout. Original masters retain all original pixels.
