# Language of Sound / Language of Vampires — Nathan Tabor

Complete source snapshot from the 123 Universal Language Learner, integrated into the main Bible app.

- 164 registry records; 14 adapters; 228 batch operation/parameter combinations.
- The sound bridge includes five Spanish lessons and a curated starter vocabulary, not unrestricted automatic translation.
- Original cipher names and statuses retained. Catalog-only records do not run without their missing source algorithm.
- Omega adapter checked against the recovered Python implementation with Unicode fixtures.
- Settings and learner notes are browser-local; JSON export provides portable copies.
- Four generated artwork briefs are preserved in integration.json. Exact image files were unavailable after workspace cleanup and must be restored before claiming the artwork is included.

Open index.html through a static HTTP server. From the main Bible app choose Language of Sound. Its passage handoff transfers the exact entered text and reference through same-origin session storage.
