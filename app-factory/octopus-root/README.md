# 🐙 OCTOPUS ROOT — Infinite Tentacles and Sucker Cup Receptors

**NATHAN AI × THE MIDDLE C × TABOR 1-2-3 FACTORY**

The shared root of the game is a local-first graph. Tentacles are directed links between independent nodes; sucker cups are type-specific checks; the Cookie Monster Octopus is a recoverable review bin for duplicate, incorrect and unsupported links.

## Five jobs

1. ROOT: retain original names, formulas, projects, origins and stable namespaced IDs.
2. BRANCH: grow transformations lazily, in finite batches. The idea can continue to expand indefinitely across sessions, but no browser performs literally infinite calculations.
3. SUCKER: test an exact glyph match, true character reversal, true word-order swap, declared cipher, symbolic association or sourced/documented claim.
4. STICK: attach only if the selected rule is satisfied. A supplied URL is not independently verified proof.
5. COOKIE MONSTER: preserve failed proposals and reasons for repair; do not automatically delete source material, censor game text or label people as garbage.

## Starter gates and claim boundaries

- Arithmetic formula Aₙ = a₁ + (n−1)d has selected glyphs **AAND**. AARON is a cipher/association, not an exact extraction.
- AAND → Aaron and Moses is a Middle C connection, not a mathematical implication.
- Geometric Gₙ = a₁ r⁽ⁿ⁻¹⁾ has selected glyphs **GAR**; the fish-name reading is a letter puzzle.
- Harmonic mean H = 2xy/(x+y) → HEAVEN BELOW / HELL ABOVE is symbolic spatial mapping, not a physical mechanics result.
- DIRTY CLEAN ↔ CLEAN DIRTY is a word-order swap. That differs from reversing every character.
- The Nathan Tabor SQUARED AND ROUND / 🖕🖕 expression remains a named symbolic gate.
- ABBA appears in the letters of a+b=b+a. Any ancient-language or religious history requires separate sources.

## Project boundaries

Use engine.js from a browser or Node/CommonJS. The public API provides create, check, attach, retry, addNode, grow, save, load and adapter.

The adapter(namespace) function returns a **read-only projection** for a product namespace. Connecting Middle C, Math Roots, ancient archives, games and other Factory products needs explicit consumer integration; this module does not crawl external sites or accounts, share private data, publish content, validate spiritual/physical claims or access other apps.

The browser demo saves to the local browser profile. Export a JSON backup separately to preserve data after browser resets. Import marks all existing edges **imported-unverified**; this is deliberate.
