### NUMEROLOGY (explicit *modern* transformation)
For Latin A–Z, define a letter value v(A)=1 through v(Z)=26. **A1–Z26 score** is the sum of those values; **1–9 cycled score** uses 1+(v−1 mod 9) for each letter; **digital root** for an integer n>0 is 1+(n−1 mod 9), with 0 retained as 0 for a mathematical total of zero. Input is Unicode NFKD normalized for Latin letter accents; non-Latin mathematical symbols, Egyptian glyphs, and Greek letters remain in the original label and are **not** reinterpreted as English letters. Integer/decimal text tokens are preserved as text. This is modern pattern/cipher design, **not** ancient Egyptian gematria, not an agreed etymology and not a proof of science.

Per-node scored values are displayed in bases 2, 3, 7, 9, 10, 12, 13, 17, 21, 33 and 69, calling the existing [TABOR Golden Radix Ladder](../../../radix-ladder/engine.js) to ensure consistent digit alphabets and reversible encodings. Example: **MIDDLE C** → M(13)+I(9)+D(4)+D(4)+L(12)+E(5)+C(3) = **50**. Modern 1–9 cycle gives **32**, while the first sum's digital root is **5**. A different cipher can produce a different score; the input rule must be named.
