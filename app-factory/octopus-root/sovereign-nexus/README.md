## Sovereign construction rules

- **1 + 1 = 2:** The source branches keep separate modules, independent namespaced IDs, local data and owners. A symbolic edge is knowledge, not a merged database.
- **1 − 1 = 0:** A pack is opt-in and may be left unselected. No background job continues, and no remote access permission is created.
- **YES IS YES / NO IS NO:** All six pack switches default to OFF. PREVIEW computes changes only in temporary memory. ATTACH requires another deliberate checkbox and button click.
- **NO LOSS:** The bridge refuses duplicate/conflicting names, partial Codex ingestion, invalid root snapshots, and capacity overflow. Every existing node, edge and Crumb Reaper review record must remain unchanged and in order. The ROOT still has a **600 node limit**; a clean six-pack installation yields 461 nodes, 486 links and 0 reviews.
- **SOVEREIGN ROLLBACK:** The browser stores a local previous Root snapshot *before* writing a proposed graft. Automatic undo is refused if the current state differs from the committed post-graft receipt, preventing an undo from overwriting newer user edits. A user should export both the Root and any separate app backups.
- **NOT AUTHENTICATION:** The Sovereign Bubble's invitation/permission model and these browser checkboxes are examples of *local user choices*, not server-verified grants. The [shared contracts](../../core/root-contracts.js) explicitly require a trusted server context for true cross-tenant authorization.
- **MATHEMATICS ≠ FICTION:** Game attack nodes are fictional, while the mathematical models retain their assumptions and boundaries. No equation is converted into a real device or weapon.
- **NO REMOTE SIDE EFFECTS:** The Nexus does not access bank/payment/medical data, connected accounts, browser credentials, phone location, a user file vault, or other applications' localStorage. It makes no requests to an external server and does not publish, update or delete code outside a local graph.

## How to use

Open [the Sovereign Nexus](./index.html). Review **ROOT STATUS**, choose one or more unchecked pack boxes, click **PREVIEW MY CHOICES**, review counts and source boundaries, explicitly approve, then choose **ATTACH THESE ROOTS**. The engine recomputes and compares the preview hash before writing and saves a local backup first. To undo, use **UNDO LAST NEXUS GRAFT** before making any other Root changes.

The checksum is a short deterministic comparison tag for detecting local changes, **not a security, signature, ownership or integrity guarantee against an adversary**. Backups in browser localStorage may be lost when site data is cleared. Always export your Root JSON separately.

The **Open Your Other Roots** directory is only a verified static set of local links. It does not pretend to have installed, transferred, authorized or synchronized the data belonging to those separate products.
