# MAKE a SNOW GLOBE · Nathan Tabor

[Live studio](https://tabor-bridge.nathantaboract.workers.dev/make-a-snow-globe/) · [The History of Snow Globes](https://tabor-bridge.nathantaboract.workers.dev/history-of-snow-globes/)

Design 1-, 3- and 6-globe layouts, choose a scene per chamber, and export the design JSON, rendered PNG or printable maker sheet. Browser storage stays local. Production prices in the studio are proposed USD budget ranges. Makers independently quote feasibility, tooling, shipping and taxes. Multi-globe structures require an individual quote. The site contains no ordering or payment flow.

Run `npm test` to build the dispatch Worker and test the layouts, design round trip, maker-sheet pricing and asset routes. Publish `.release/worker.mjs` as `make-a-snow-globe` in the Tabor Academy dispatch namespace. The Tabor Bridge passes the independent public mount to the studio. The History app links to the studio and hosts the alternate cover. The holiday-universe text preserves the four supplied sections.
