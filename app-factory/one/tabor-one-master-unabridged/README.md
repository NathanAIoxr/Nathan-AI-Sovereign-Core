# TABOR ONE — MASTER UNABRIDGED / ADDITIVE RESTORATION

**Purpose:** compile all available uploaded sources and all three previously produced packages **without replacing, shortening, or rewriting them**. The ZIP archive is only a delivery container; the extracted files are not summarized or compressed in content.

## Start

- Open `index.html` for links to both offline browser systems.
- Run `python master.py 'UNO DOS TRES CUATRO'` for simultaneous output from the full-language module and quad-axis cipher.
- Run `python -m unittest discover -s tests -v` to validate the merged launcher.
- Run `python scripts/verify_integrity.py` to check the original files against the SHA-256 manifest.

## Source precedence and restoration policy

- Original user-authored wording is preserved in the source text, rather than silently substituted by a rewritten description.
- A later assistant-created file is **not** allowed to overwrite an earlier user's original manuscript or a previous version.
- If two versions conflict, both stay in their original versions; the comparison is documented.
- Historical claims, hypotheses and designs keep distinct evidence tags. An unverified assertion is not silently declared true or false; it remains available for investigation.
- NO GRAY/ GREY AREA is applied to the **final inclusion / exclusion decision**, while source uncertainty remains clearly recorded.
- Avoid operational claims of absolute security, authentication, automatic lie detection, or irrefutable historical ancestry where none has been demonstrated.
