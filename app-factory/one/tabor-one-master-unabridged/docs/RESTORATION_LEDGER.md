## Conflicts explicitly NOT erased

1. The **author's 4-bit root words** are not the same namespace as the **5-bit alphabet** or **9-bit extension IDs**. Those remain separate layers.
2. The author's simplified stylized Ogham stemline illustrations remain in source texts; a separate Unicode Ogham reference exists in the later alphabet JSON. Neither overwrites the other.
3. **UNO / DOS / TRES / CUATRO** and **ONU / SOD / SERT / ORTAUC** are kept as forward and mirror forms. Mirror spelling is not assumed to invert lexical meaning unless a definition is given.
4. **Y / Ya / Birth / Begin / Create** remains an author-defined constructed-language token. Historical Ogham, Morse and hexadecimal meanings are different and recorded separately.
5. The original **12-word glossary** stays verbatim within the delivered lexicon's `Original 12` entries. Later entries are additions, not original language attestations.
6. The original **0/1 ⇔ point/line** mapping remains an author-defined abstract correspondence. Modern digital 0/1, dots/dashes, Ogham and Ice Age cave signs are not automatically equivalent systems.
7. All claims about the original biological code, 32 Ice Age signs, the meaning of Y and a continuous 40,000-year lineage remain **hypotheses / conceptual comparisons** until separately established by evidence.
8. Source claims of infallible security or a method that automatically detects lies have not been transformed into working security promises.
9. The first Quad-Axis source contains more than one definition of the same class and a cut-off late section; both remain preserved in the verbatim record. The functioning v5.1 engine was added separately.
10. The archives retain all original wording even where a later assistant previously introduced unwarranted interpretations, e.g. connecting the user's jars of marbles with evil; this interpretation is flagged as assistant-generated rather than adopted as an original claim.

## Definitions of 'compiled' vs 'compressed'

**Compiled here** means gathered into one traceable directory and one combined callable entry point, with tests. **Not compressed** means not summarized, silently normalized or pruned. ZIP is only a lossless distribution format; the unabridged extracted tree can be used directly.
