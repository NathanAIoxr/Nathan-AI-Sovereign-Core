## Online / offline operating boundary
An internet-accessible public website can serve users worldwide **where a route to GitHub Pages exists**. It does not appear spontaneously on offline devices. To operate without Wi-Fi/mobile data, a device must first download/install the required public pages through a connection or via a locally transferred package. This repo module does not deploy physical radio meshes or transmit between disconnected devices.

No uncontrolled network interception, corporate telemetry modification, external device-port locking, AI self-awareness, firmware override or global forced operation is claimed.
