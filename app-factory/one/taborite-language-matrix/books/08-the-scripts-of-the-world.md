# Volume 8 — The Scripts of the World

**The Taborite Universal Language Matrix — by Nathan Tabor**

*A cataloguing method for alphabets, abjads, abugidas, syllabaries, and logographic systems*

> First-edition short manuscript. Research and interpretation are separated; see the series notes.

## Chapter 1: Not Every Sign Is a Letter

The word alphabet is too narrow for a universal language archive. Some writing systems chiefly record consonants, some attach vowels to consonant bases, some use syllable signs, and some contain characters whose functioning combines sound and meaning.

A universal catalog should record the kind of writing system as well as its visible marks. Treat an undeciphered system as undeciphered. If scholars disagree about its classification, retain that uncertainty in the record.

The catalog can begin with a small, trustworthy core and grow through documented additions. A claim of universal coverage is a research goal, not a completed translation database.

## Chapter 2: Direction, Depth, and Context

A text may run left to right, right to left, vertically, or according to inscriptions and display conventions unlike modern pages. A Unicode string provides a sequence of characters; the displayed order may be shaped by bidirectional layout rules.

Preserve the original code points, normalized and non-normalized forms where relevant, script tags, and the surrounding context. Do not discard combining marks, spacing, punctuation, or diacritics to make a string fit a preferred graphic.

That discipline allows the same archive to store Arabic, Hebrew, Devanagari, Chinese, Ogham, runes, and modern text without claiming that all are structurally identical.

## Chapter 3: An Honest Atlas

For each writing tradition, provide a source inventory, geographic and time range, writing direction, sign list, attested language or languages, phonetic conventions, and citations. Add a field for manuscript variants and one for undeciphered signs.

The interface should clearly separate searchable metadata from proven decipherment. It may carry an image or drawing as an object record while preserving the fact that the sign's pronunciation is unknown.

A true universal atlas gains authority through the accuracy of each entry, not through an unsupported promise that one formula reveals all meanings.
