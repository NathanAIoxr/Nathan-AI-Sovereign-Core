## Original logic preserved

The **unchanged Version 2 matrix** remains at matrix.html. No existing repository files were overwritten. The new game and book reader are additive companions. The original four families remain:

1. Beithe (B L F S N)
2. hÚatha (H D T C Q)
3. Muine (M G NG Z R)
4. Ailme (A O U E I)

The 20 original signs are distinct from five later forfeda and the supplementary Peith sign. The **universal** mode is a new fixed-width base-20 encoding of Unicode code points; it neither translates a language nor performs cryptographically secure encryption. The history of Ogham is not identical with the user's new symbolic readings.

## Local play

Open index.html and use the three large section selectors. Open game.html directly for the expanded gaming space. In game mode, correct responses award points and increase streaks. Best scores are saved in localStorage, when available. There is a reset button. Game questions use verified glyph positions; word challenges read modern Latin-letter equivalents, not medieval Irish texts.

The book reader loads an included JavaScript catalog locally. Choose a volume and chapter. Download each Markdown manuscript if desired. Reading progress remains in the browser. These first-edition volumes are **short book manuscripts**, not full-length novels or commercial publications.
