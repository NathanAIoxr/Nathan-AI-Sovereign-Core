Verification protocol

  1. Store the original wording without overwriting it.
  2. Record a later name or address as a separate field.
  3. Attach dates, source type, and links. A matching road number is not proof of an official rename.
  4. Mark unresolved or conflicting records clearly until primary-source evidence is found.
  5. Keep people’s current residences and current telephone data out of the historical map.

Local data controls

Changes save only in this browser using localStorage. Export a JSON backup whenever you want. Importing another JSON replaces the browser copy only after confirmation.

Private entries are masked by default in the index and excluded from default exports. You can reveal them locally to edit.
