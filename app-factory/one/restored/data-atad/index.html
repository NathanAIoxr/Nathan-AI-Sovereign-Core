System Architecture & Provenance

Creator's operating principles

1 + 1 = 2 — BUILD. 1 − 1 = 0 — CLEAR. Preserve original words and source code. Keep fact, hypothesis, analogy and fiction distinguishable. High-impact actions require approval.

Architecture: NATHAN AI → TABOR ROOT → TABOR 1-2-3 FACTORY → ONE APP.

What is actually running?

HTML/CSS/JavaScript, Unicode text operations, UTF-8 encoding, multiple asynchronous analysis tasks, WebCrypto source hashing where supported, local archive import/export, and optional device speech APIs.

Not installed: a trained neural model, sentience, physical body, autonomous internet search, model-provider integration, cross-device cloud memory or a real custom processor.

Privacy and limits

All text transformations work without networking. Browser storage is convenient but not an encrypted backup. Export records regularly. Speech recognition, when supported, may be processed by the browser vendor's speech service; use it only if you accept that service's privacy behavior.

Open-source integration

Keep this as an additive module; do not overwrite other Nathan AI projects. Suggested repository placement: app-factory/one/data-atad/.

Verify in Node with node --test test.mjs. Current prototype is standalone and can be hosted with static files.
