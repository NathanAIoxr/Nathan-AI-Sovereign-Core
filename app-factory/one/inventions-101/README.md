## Integrity and safety

The source descriptions are **authored descriptions**, not evidence that a product was manufactured, independently tested, sold, patented, or approved. In particular, heated elements next to fleece or combustible materials, very large electrical installations, chassis alterations, wheeled load systems, archery targets, fertility compounds, copper ingestion, and water purification require qualified technical or medical review. No engineering certification or clinical efficacy is claimed.

The catalog is **public** reference text included in the GitHub source for the ONE browser interface. It must not absorb private raw manuscripts, confidential files or personal medical records. Export produces metadata only. No source editing, hidden server access or unapproved device operations are implemented.

This module is not a replacement for the separately maintained owner originals. The original descriptions in the submission are preserved as record fields and the book draft carries its own explicit provenance.
