# ONE — Sumerian Truth, Falsehood, App / Game / Books

A standalone, additive, no-dependency learning module. Open [index.html](index.html) in a browser. Includes four tabs: Language App, Truthkeeper 8-Gate Game, Books (eight original companion chapters), and Verbatim Source Archive.

## Design constraints
- No humans, figures or faces.
- All author-supplied quotations remain verbatim in the source ledger; interpretative passages are separately identified.
- Ancient Sumerian **níĝ-gi-na** (truth/justice) and **níĝ-lul** (falsehood/deception) are not the Latin-derived personal name **Niger** (Acts 13:1).
- The game asks evidence-based questions; a wrong answer is educational, not moral judgment.
- Works as an offline static HTML page with no analytics, accounts, paid services or dependencies.

## Books
The interactive reader provides eight **new companion microchapters**. They are not falsely represented as an imported full manuscript. The title is preserved exactly:
**NOW = NIGGINAS’ OBJURGATING WAHEGURUS** — By Nathan Tabor.
