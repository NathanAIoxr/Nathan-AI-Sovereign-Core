# Joy Studio changes

## v0.2 — November 5, 2026

- Added playable 8-pair Memory Match, 25-Door memory journal, 5×5 family Bingo and a 20-prompt inspiration machine.
- Added game stars, levels, achievements and creative quest checklists with local progress saving.
- Added 24 festive stickers, four one-click templates, undo/redo, layer duplication, keyboard nudge and grid snap.
- Added recurring annual dates and one-click event-to-scrapbook creation.
- Added family fridge magnets, local consent notebook, writing templates, read-aloud, library search/filter/duplicate and browser-native device file sharing.
- Added optional installable PWA with static-only offline cache and PNG icons; standalone single-file offline version still works.
- Preserved the existing v0.1 data key and original formats to keep prior local projects importable.
- Security: no private/dark-web scanning, no remote wipe, no external service or automatic rights enforcement.
- All tests and local browser smoke checks completed before packaging.
