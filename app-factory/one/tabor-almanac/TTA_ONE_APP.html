What is implemented, and what remains

The original Mythic Match and Tábor Spiral engines are retained. The 33 Trial Matrix uses new working rule adapters. Level 33 currently cycles five compatible rules on an 8×8 board; the complete 32-profile geometry transformation engine is unfinished. Visuals use animated vector-style glyphs and CSS effects, rather than full 3D character rigs.

Unspecified rules have explicit prototype choices: independent Mayan boards; 49 active Rhombus nodes with visual voids outside the board; fixed Babylon spokes; one monopoly clone per two moves; both failed memory-swap slots burn; press widths 8/8/6/6/4/4/2/2; Panopticon tracks pointer dwell; Subliminal Canvas uses a non-flashing veil. Temporary ledger locks are local game rules, with no cryptocurrency or external blockchain.

Source, scope & original implementation
The original Python reference uses independent multiprocessing input/output queues for each axis. This app adds a JavaScript/Web Crypto adapter with two separate workers; it does not run Python in the browser. Both implementations recompute hashes rather than invert them. Asynchronous operation does not make continuous hashing low-power.
Header proof-of-work checks alone do not establish transaction validity, expected network difficulty, chain membership, mining-pool connectivity, revenue, or complete Bitcoin consensus. This module does not submit work, request a wallet, or make network requests.
