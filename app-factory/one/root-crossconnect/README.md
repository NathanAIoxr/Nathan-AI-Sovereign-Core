# ONE Root CrossConnect — Additive Index v1

A text-and-symbol-first, static, no-external-dependency explorer joining the **three 26-slot user-authored matrices**, **31 reconstructed or proposed proto-forms**, **22 Hebrew alphabet positions**, **20 writing/religious comparison records**, and **10 links to existing ONE modules**.

Open [Root CrossConnect](./index.html).

## Architecture and preservation

- **Does not replace or edit** `app-factory/one/connected`, `app-factory/one/nathan-matrix/sovereignty-origins`, original books, old transcripts, manuscript data, or the private ONE Library/Vault.
- Keeps user-authoritative Alpha→Zlpha / Zlpha→Amega names in separate fields; Greek is a **chosen 26-slot arrangement**, not the complete historical Greek alphabet across all periods.
- Displays evidence classes: attested, reconstructed, hypothesis, comparison, author-framework. The asterisk on a linguistic reconstruction does **not** make every proposed derivation correct.
- Cross-links existing ONE modules through navigation; no external file contents are silently imported. Keyword search makes related records discoverable across sources.
- Hebrew gematria/Atbash map is **traditional** and not demonstrably encoded in the earliest alphabetic pictographs. Conflicting letter associations are not equated with settled historical meaning.
- Does not assert that religious triads share a single lineage or that a particular institution removed a mother deity without primary evidence.
- An author-approved connection remains distinct from independently verified history.
- This is a **curated starter graph/index**, not a claim that every one of the 3,796 tracked repository paths or private sources has been ingested.

## Files

- `index.html`: searchable self-contained browser interface and explicit export to `one.root-crossconnect.v1` JSON.
- The generated JSON contains the records presented on screen; exports are local browser downloads.

## Core invariants

`1+1=2` build, `1-1=0` clear. A zero denotes unverified where a verification state is requested, not a judgment on the value of a human or culture. Never rewrite original words or collapse a hypothesis into a documented fact.
