# THE DIXIE CULT — by Nathan Tabor

Standalone **additive** ONE module: web interface, installable progressive web app, twelve-gate phrase game, source library, reverse-reconstruction research, and books.

Open `index.html` in a browser for the website/game (offline caching requires HTTP(S) rather than file://). No analytics, tracking, accounts, subscriptions, or external JS dependencies. The exact author words are in `ORIGINAL_SOURCE.txt` and `data/canon.json`.

The research materials and instructional prompts are **new companion writing**, not attributed to Nathan Tabor as verbatim quotations. No user-authored line has been replaced.
