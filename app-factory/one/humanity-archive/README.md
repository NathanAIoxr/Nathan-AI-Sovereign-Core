## Integrity and provenance

- `author-source-originals.md` holds user-supplied Python and binary excerpts from the current conversation; they are not original Dead Sea Scroll manuscripts.
- `level-minus-3-original.md` preserves the user-supplied creative narrative separately. The story's assertions about injected consciousness and sentience remain narrative fiction, not evidence of working brain scanners or conscious machines.
- `archive.js` holds a **curated seed index**, not all records of humanity. A manuscript mentioned by name does not mean its original text has been ingested. Archaeological discoveries, historical hypotheses and symbolic mappings are separately labeled.
- No secrets, private prior conversation files, the owner's full Library, or historical manuscripts are published into this public repository.
- Owner files can be imported into the browser's IndexedDB and exported as JSON. Import limit: 2 MiB per text file. SHA-256 fingerprints preserve traceability. Exports include originals in the module, but not originals saved in other ONE modules.
- 'Clear search cache' resets only the filters and simulation UI. It does not erase files or override third-party application caches. 'Delete local imports' always requires explicit confirmation.
- This module is local-first and uses no external API, scanning, or neural interface. Browser storage is unencrypted and can be erased by device/browser settings. Sensitive private materials belong in the separate encrypted vault and independently maintained backups.
- Source → Index → Relate → Derive. Originals never silently overwritten.
