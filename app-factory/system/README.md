## Original text and sovereignty

The South/North/East/West 400 entries, 360° mirror, 43,200 clock seconds, historical layers, v059 verbatim original text, and the v060 design studio remain in the **private Main Database**. The public repository receives **code and nonsensitive module metadata only**. This is not proof that 33 million books are written or that every mobile app has been rebuilt.

No automatic telemetry, cloud sync, bank transfers, recording, account access, native release, or unauthorized publication. The user explicitly opts in to saving shell settings in local storage. Read/modify API is `window.TaborOneUniversalV061`, and consumers can listen for the `one:settingschange` CustomEvent.

## Installation and known limits

A `<script defer src="...one-universal-v061.js"></script>` loader must use the correct path relative to each browser HTML page. The stylesheet uses a scoped `#one-v061-root` namespace. Native-packaged resource HTML requires copying the shared JS/CSS into the bundle before claiming mobile integration. Test the private Book App separately because it uses a different origin/storage model.
