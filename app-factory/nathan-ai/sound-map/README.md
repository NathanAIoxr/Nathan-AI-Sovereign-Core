# Nathan AI Sound / Vibration / Spelling Map
An additive, free, local-first personal language notebook. The source concept starts with an internal sound or hummed rhythm (such as repeated LA syllables), registers how it feels, and only then maps toward the owner's preferred sound-spelling, conventional orthography, phonetic notation, context, scripts and translations.

## Implemented
- Unicode-first mapping form: language label, original orthography, creator phonetic spelling, optional IPA, RTL/LTR, subjective harmony rating 0–10, rhythm, syllable segments, meanings/notes, related spelling and translation lines.
- Local search and deletion, import/merge/export JSON, safe literal display and defensive backup validation.
- No alteration to the existing language library, canonical Codex declaration or other modules.

## Interpretive boundaries and expansion
- 'Vibration', 'gut' and 'harmony' are preserved as creator descriptions of sensory/linguistic experience. The numeric rating is subjective, not a measured hertz frequency or objectively validated linguistic property.
- Standard orthography can differ from individual phonetic perception, dialect, allophony and IPA. Original writing is never automatically overwritten or labeled scientifically wrong.
- Future phases: large-scale licensed multilingual lexicons; linguist-reviewed grapheme-to-phoneme, phoneme-to-grapheme candidates; phoneme inventory and IPA audio; accessible recording with consent; syllable/stress and pitch contour analysis with calibrated measurements; script transliteration; fuzzy cross-language matching; reversible phonetic profiles and provenance per source; local voice/text interfaces; optional Work Vault handoff.
- There is no claim that every possible word or language is already mapped or that all languages have identical writing rules.
- Use the owner's original spoken/written source in a private source vault when explicitly imported. Do not silently publish private words in this public GitHub repository.
