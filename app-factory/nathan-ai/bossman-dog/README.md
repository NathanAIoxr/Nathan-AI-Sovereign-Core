# BOSSMAN × DOG — Street Files

Additive, offline-first Nathan AI module. **BOSSMAN** and **DOG** are recorded as creator-described street names; PINEKNOT, REAPER, STREET CREED, SMARTDONKEY, and KING OF PARADOX remain separately labeled creator-attributed monikers.

## What is active in this release

- Four deliberately different, responsive visual styles: **Concrete / Road Atlas / Caseboard / Signal Ledger**.
- Source-linked moniker index and archive leads with original-status flags.
- Five editable research lanes: mafia/organized crime, cartels, White House, Vatican, and street-level drug harms. **The lanes are inquiry subjects, not proven affiliations or accusations.**
- Local-only evidence drafts with source URL, note, evidence status and timestamp; JSON export/import and explicit local clear.
- No background checks, surveillance, account access, real-world targeting, network requests or autonomous activities.
- The public repo contains no private archival bytes, personal addresses, unverified names of third parties, or source media copied without approval.

## Source separation

The record index is sourced to the user's descriptions and existing Library art descriptions and catalog references. Source names can be listed without asserting that every named original file is currently available. The archive references include:

- `Nathan Tabor: A Force for Good.png` — Library image description, 2026-09-11.
- `Pineknot: River, Resilience, and Redemption.png` — Library image description, 2026-09-11.
- `TABOR_MASTER_PROJECT_CATALOG.csv` / `TABOR_TOTALITY_UNIFIED_v008.json` — RAW DOG / OXR Crossroads Atlas catalog entry.
- Historical DOG COMPANY tool filenames were referenced in recovery discussions; not represented as recovered executable originals.

Any claims about specific persons or organizations require independent reliable evidence. Drafts are always labeled as unverified until manually reviewed; the UI does not publish them.

## Run

Open `index.html` from the main Nathan AI hub or via a static local server. The app fetches only its adjacent `records.json` and runs entirely in the browser; local drafts stay in localStorage in that browser profile. If opened via `file://`, some browsers block JSON fetches; use a local static server.

Run `node --test app-factory/nathan-ai/bossman-dog/records.test.cjs` for schema and source-boundary checks.

## Preservation

No existing DOG, REAPER, KAP, original work, library, code, or older canon module is overwritten. The historical sources are pointers, not replacements.
