- Evidence integrity: geometric coincidence is only a candidate connection, not a civilization identification.

## Complete local application built in this session
A separate downloadable archive, `Nathan-Tabor-Lost-Worlds-Atlas-v1.zip`, contains a Python HTTP server, SQLite schema, seeded research index, graphical HTML interface, four run-on-demand worker jobs, JSON export, and five passing tests. **The full archive has not been committed to this GitHub branch.** It must be reviewed and imported before merging the full app.

## Research workflow
1. Ingest ancient accounts and named origins with exact provenance, authorship, dates, and translations.
2. Calculate antipodes, index polygons, and compare geologic bathymetry and paleoshorelines.
3. Require chronological compatibility before advancing an archaeological hypothesis.
4. Keep CERO original sources, UNO calculations, and DOS interpretations separate.
5. Store rejected comparisons and uncertainty as thoroughly as candidate matches.
