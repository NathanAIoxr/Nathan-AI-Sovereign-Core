# BOOBIES by Nathan Tabor

Poster gallery and concept archive for Nathan Tabor's BOOBIES project. The gold breast-outline and tassel poster leads the gallery, followed by the earlier arcade cartridge, full-project, and corset playbill artwork.

- [Live Cloudflare gallery](https://pub-281f12694638401cb7a5f34b42104be0.r2.dev/index.html)
- [Creator's source](public/source.md)
- [Poster artwork](public/artwork)

The website presents the project concept and its calculator wordplay. The posters are full-dimension WebP editions of the original images.

To preview the site locally, run `python -m http.server 8000 --directory public` from this directory. The live gallery serves the contents of `public/` from the dedicated `boobies-by-nathan-tabor` Cloudflare R2 bucket. Publish updates by uploading the files with their relative paths.
