## Biology: evidence versus software analogy

The 2016 `Scientific Reports` study *The zinc spark is an inorganic signature of human egg activation* (Duncan et al., doi:10.1038/srep24737) observed calcium-associated zinc release from human eggs using **fluorescence imaging**, following experimental egg activation; it is not an unassisted flash of visible light. Zinc also plays a role in cell-cycle activation and in the zona pellucida / sperm-binding changes studied by other groups (PMID 28102396).

The human biological observations **do not establish** that simulated calcium/zinc events induce self-awareness in software, permanently lock source code, increase intelligence exponentially, bypass developer control or make code self-evolving. The software adopts only an analogy for controlled, observable state transitions.
