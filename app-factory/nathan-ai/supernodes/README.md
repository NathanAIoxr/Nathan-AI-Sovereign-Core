## Sovereign database model

Each valid address N has the deterministic namespace supernodes/NT-XXXXXXXXXXXX, with its own inherited rules and separately stored records. The shared physical IndexedDB uses object stores named nodes, knowledge, and incidents, and scopes records by the node identifier. Only consented, deliberately accessed nodes are created in persistent storage.

**Logical namespace is not a physically isolated server or cryptographic security boundary.** Browser origin scripts may read all local IndexedDB data. Sensitive data, biometric information, names of victims, contraband, and secrets must not be entered. A real multi-tenant sovereign infrastructure would need verified authentication, individual keys, encryption, access control, separate storage authorities, quotas, consent records, audited backups, and migration/recovery.
