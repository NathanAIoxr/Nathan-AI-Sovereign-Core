# Nathan AI — Dewey Decimal × Duodecimal Conductor
Independent HOLD-zone project. **Decimal primary; Dewey Decimal classification and duodecimal/base-12 separate rails; binary is a translation, not governing classification.** Source naming CERO DECIMAL (0, LA, AL), UNO DECIMAL (1, EL, LE); DOS is a separate verification role, not a replacement of CERO/UNO. Preserve LOC, Ranganathan PMEST, and right-to-left mirror keys as additional distinct rails.

Dewey labels are subject classifications, not base-12 numbers. Duodecimal uses 0–9, X=10, E=11 (source-defined glyphs; conventional A/B aliases can be imported explicitly). Example 999 decimal = 6E3 base-12. This project never asserts its provisional Dewey subjects are official catalog assignments.

Agents: CERO source reader, UNO normalizer, DOS verifier, ALPHA build receipt, BETA independent check, CONDUCTOR HOLD router. Each project remains in its own virtual HOLD enclosure and database namespace; this does not create unlimited actual DNS zones. Original project-specific tables are preserved.

Historical source: GONNECT CERO/UNO Decimal v3, Universal Matrix RTL mirror, TABOR 1-2-3 FACTORY, Library of Tabor, and 1000-category Dewey proposal. All external imports must be authorized and source-provenanced.

Run: `node --test src/index.test.mjs`. Deploy only to a verified existing Worker route with valid D1 binding and access control. No autonomous scanning or self-replication.
