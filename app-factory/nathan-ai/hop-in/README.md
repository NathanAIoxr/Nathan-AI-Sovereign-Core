## Working scope

A responsive, offline-capable-by-local-server (not a PWA/offline cache) browser entrance with no packages, no external requests and no unsolicited people/faces:

- Three natural controls: TALK, EXPLORE, BUILD; A–Z navigational directory with 26 letters.
- Optional name transformations: Unicode-aware forward/backward characters, reverse words, case, initials, accent-folding for search. **Neither reversals nor phonetic similarities establish origins or family relationships.**
- Optional Gregorian date input rendered through browser-supported ICU/Intl calendars. An unsupported calendar is clearly marked; Islamic observational dates and historical national adoption rules may differ. Tabor Almanac 12/13/17/21-month groupings are **illustrative** pending canonical creator algorithms.
- Time slider 600 BCE–2026 CE, micro/macro slider, historical research anchors and an explicitly **imaginative** perspective prompt; time travel/remote sensing are not literal.
- Historical Assembly research comparison for Buddha, Jesus, Martin Luther King Sr./Jr., King James. No fabricated first-person dialogue or direct quotations.
- Source-check protocol: record, date, variants, interpretations and uncertain claims. A user-chosen interpretation is not mechanically established as fact.
- User-authored belief/mind creator (never presented as an actual God, authoritative revelation, or a person that has been contacted).
- Above, Middle, Below, Beyond symbolic categories plus **separate**, unverified user-entered family notes.
- Local route guide links to the existing Nathan AI Assistant, ONE Library Mind, Family Research, Consumer Editions and Universal Workspace. It is **not** an LLM and does not send any messages to a model.
- Client-only export and explicit clear; no analytics, accounts, location, login, back-end queries or automatic storage added by this module.

## Source and privacy boundary

The public GitHub repository is not the complete private library or a live worldwide scanner. The actual `101` canonical root settings have not been recovered from a verified original list. The supplied categories are a **partial specification**; do not invent missing parameters to reach a count. No private names, birthdates, family data or API credentials are committed. Historical, theological and symbolic interpretations are labeled separately from verifiable events.

Design principle: Preserve originals; add a separately namespaced entrance and additive interfaces.
