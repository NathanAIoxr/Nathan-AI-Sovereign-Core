# Anchored Mirror — Pot Owner
Independent HOLD project. Implements the user's **Rainbow Chaser vs. Pot Owner** model as an auditable accounting simulation. Do not merge independent pots/projects.
- Rainbow chaser: price speculation, leverage, momentum (not implemented).
- Pot owner: measured receipts from **authorized** services, infrastructure, transaction fees, or owned compute; each requires real customer contracts, permissions and actual receipts.
- Multiple mirror-side pots: one ledger per independent project, never aggregate as if money has been received.
- 1+1=2 BUILD, 1−1=0 CLEAR, 1×1=1 INTEGRATE, 1÷1=1 VERIFY.
- Energy costs, fees, compute and other costs subtracted before computing net.
- HOLD on loss threshold; no trades or real-world automatic stop-loss orders.
- Optical rainbow geometry is a conceptual metaphor, not a guarantee of profit.
- No wallet operations, mining activation, automatic charging, or access to external infrastructure.
- Tests: `node --test app-factory/nathan-ai/anchored-mirror-pot-owner/src/engine.test.mjs`.
- Integrate with existing independent projects only through explicit approved, read-only adapters.
