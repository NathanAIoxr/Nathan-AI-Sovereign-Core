# The Two-Plate Reckoning

Nathan Tabor’s Sunday buffet satire as a standalone game, installable web app and seven-chapter short book.

- [Play the Sunday shift](https://tabor-bridge.nathantaboract.workers.dev/two-plate-reckoning/)
- [Read the book](https://tabor-bridge.nathantaboract.workers.dev/two-plate-reckoning/book)
- [PDF edition](public/The-Two-Plate-Reckoning.pdf)
- [Related two-plate proclamation](https://tabor-word-rotations.nathantaboract.workers.dev/word-history/proclamation)

The fictional preacher eats 12 portions. His wife eats nine. The book and game portray how each person builds and eats two plates. Checkout uses a fictional $36 bill and a 20% tip of $7.20. The book attributes the server accounts and cites the Department of Labor wage guidance.

Run `node --test game.test.mjs` and `node build.mjs /tmp/two-plate-reckoning-worker.mjs` from this directory. The build emits one Cloudflare Worker module. The editable manuscript is `book.json`.
