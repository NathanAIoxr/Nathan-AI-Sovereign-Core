# The Two-Plate Reckoning

Nathan Tabor’s Sunday buffet satire as a standalone game, installable web app and nine-chapter short book.

- [Play the Sunday shift](https://tabor-bridge.nathantaboract.workers.dev/two-plate-reckoning/)
- [Read the book](https://tabor-bridge.nathantaboract.workers.dev/two-plate-reckoning/book)
- [PDF edition](public/The-Two-Plate-Reckoning.pdf)
- [Related two-plate proclamation](https://tabor-word-rotations.nathantaboract.workers.dev/word-history/proclamation)

Rev. Buford Gravywell eats 19 portions. Lottie Mae Gravywell eats 17. Both are fictional characters from Lonesome Gravy Fork Independent Baptist. The book and game show how each builds and eats two plates. The meme maker exports four designs as PNGs, with optional custom captions and a receipt from the game. Checkout uses a fictional $36 bill and a 20% tip of $7.20. The book attributes the server accounts and cites the Department of Labor wage guidance.

Run `node --test` and `node build.mjs /tmp/two-plate-reckoning-worker.mjs` from this directory. The build emits one Cloudflare Worker module. The editable manuscript is `book.json`.
