## Separation policy

Every program retains its original title, source directory, owner attribution, version history, processes and named function. This edition system creates **additional views** rather than moving, collapsing, silently editing or replacing historic original files.

- Each of **11 original source families** has an independent entry URL under a directory named for that original.
- Each family has **4 independently addressable edition modes**: ?form=app, ?form=game, ?form=book, ?form=academy. There are 44 view routes, NOT 44 recovered executable source programs.
- The **App** mode is a functional local-only source and process workbench, with user-selected UTF-8 file imports, SHA-256, verbatim file-byte re-export, derived notes and checklists. The specialized historic software stays at its original link.
- The **Game** mode is an interactive three-round educational adaptation with scoring, feedback and replay.
- The **Book** mode is an independently exportable Markdown reading workbook. It preserves documented public original headings and exact verified author quotations; imported original text is kept distinct from derived draft notes. This is not a claim that the user's entire manuscript archive was recovered or that full-length original novels have been generated.
- The **Academy** mode has three source-led lessons, checklist, a quiz, local note taking and JSON export.

## Restoring words without publishing private sources

- Program titles and the exact verified author statement for ROOT → CLEAR → BUILD are stored separately from newly authored game prompts, workbook chapters, explanatory notes and source-stage labels.
- No private author archive, confidential diary, original unpublished book, credentials, wallet secrets, family records, or unverified historic code is copied into this public repository. The original files have not been replaced, uploaded, or claimed complete.
- Use the **local file importer** to inspect your own original UTF-8 text. A SHA-256 fingerprint is calculated in the browser. The exact original imported file **bytes** are retained in memory for a separate export; a derived Markdown export is a decoded reading copy and not promised byte-for-byte equivalent.
- No source or journal is stored persistently by default. User-chosen exports remain private to the local device unless the user deliberately shares them.
- The original Dehack/Deliver source headings and all 104 A–Z titles stay in their existing catalog. This registry does not rewrite the 101-heading/104-entry discrepancy or pretend all 104 programs are complete.

## HOP IN Chatbox integration

All independent editions offer **Continue this program in Nathan AI Interactive Chatbox**.

1. The user explicitly selects the handoff.
2. Only public title, program ID and edition type are placed into short-lived same-origin session storage. No imported text, file bytes, personal notes, or messages are transferred.
3. A small additive bridge in the existing HOP IN chatbox validates the original identity and pre-populates a **draft for review**. It never sends a chat message or model request.
4. The visitor presses Send in HOP IN, where the existing local guide/source review and separately opt-in model workflow remain subject to their own controls.

Each edition can also be opened directly; same-origin browser storage is not required for the original program or game/workbook/academy operations.

## Source boundaries and release status

Source-backed protection tools are not certified antivirus, ransomware recovery, truth detection, automatic historic-language correction, or OS security enforcement. Historical Hack D Hack design has no independently recovered executable in this repository. Five-Matrix printing is a browser simulation with no physical printer activation. The 11 program shells are functional independent educational workspaces and routing surfaces, not completed replacements for every original.
