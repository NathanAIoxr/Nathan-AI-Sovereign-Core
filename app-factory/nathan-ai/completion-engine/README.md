# NATHAN AI — SOURCE-LOCKED COMPLETION ENGINE

This is the first additive project-finish pipeline for Nathan AI / ONE. It starts with A/V/ANCIENT source recovery and links existing Ancient Divine Roots, Six Dogs, and Sovereign Acro-Matrix projects. Existing code and original source files are not rewritten or replaced.

[Open the local browser console](index.html) · [Inspect engine](engine.js) · [Tests](engine.test.cjs).

## The governing protocol

**100% YOUR WORDS:** Exact source text, not imagined reconstructions. An indexed title is not an original manuscript body.
**100% YOUR TONE:** Author approves any proposed edits before substitution.
**100% COMPLIANCE:** Jurisdiction-, license- and task-specific review, never a blanket legal guarantee.
**100% FUNCTIONAL:** Evidence-backed end-to-end tests, accessibility and final approval—not a promise.
**NO SILENT DELETION:** Original references and audit history remain distinguishable from revisions.

## Eight completion gates

1. Original source recovered — exact source and verifiable reference.
2. Original wording preserved — source/output comparison and version.
3. Author tone approved — explicit owner-approved copy.
4. Functional requirements demonstrated — actual tests and behavior.
5. Regression and accessibility — test reports and unresolved bugs.
6. Privacy and security review — classified data and scoped controls.
7. Applicable legal/policy review — licenses, jurisdictions and reviewer.
8. Final owner acceptance — specific version and release approval.

All eight start **unreviewed**. A passing gate requires a named reviewer and evidence reference. Changing source resets source, words and owner acceptance gates. The label **ALL TRACKED GATES REVIEWED** appears only when all eight are reviewed-pass and the stage is released; it does not mean perfection or legal certification.

## Privacy and exact text

Public GitHub holds source code and general project links, not the private catalog or author manuscripts. LocalStorage is opt-in and **not encrypted**. Export/import is user-controlled JSON. Public-summary exports include explicitly public entries only, without original wording, private evidence or sensitive project records. No automatic publishing or rewriting.

## Research scope

The 66,600 generated A/V-ANCIENT combinations are **research queries**, not verified works or historical connections. Visual inversion is not proven etymology.
