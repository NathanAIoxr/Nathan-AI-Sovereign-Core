# Nathan AI — Universal Cartographic Core

**MAMMAL ⇄ LAMMAM · public-safe edition.** By Nathan Tabor.

[Launch this app](./index.html)

This **standalone, local-first** app connects seven continental research layers, Earth/atom/body/cosmos comparisons, an A–Z navigator, a seven-stage interpretive map perspective, schematic geological time, the Cosmic Ocean orientation metaphor, a private memory journal, a 13-volume outline generator, ROVERSAL word transformations, and a 75/25 community barter calculator.

## Data boundaries

- **Public code only.** This module contains no pasted personal archival transcript, private residential coordinates, family records, medical information, credentials or purported eyewitness records.
- The Memory Matrix starts empty and saves to the **local browser** only. There is no telemetry or hidden synchronization.
- JSON import/export is user-initiated. Exported memories may contain private information: do not check them into this public repository.
- Documentary records, hypotheses, metaphors, cosmological interpretations, fictional worlds and invented story scenes are **separate types**. A fictional scene never creates historical evidence.
- Review sovereignty, attribution and innocence protections before sharing any data.

## Technical status

The geological slider identifies broad time stages and **does not** compute plate reconstructions. Real tectonic overlays require a versioned GPlates rotation model and plate geometry. Earth–atom–body comparisons are interpretive mappings rather than physical identities. No external scientific datasets or personal master database are downloaded or connected automatically.

Standalone source references include GPlates, Natural Earth, NASA Earthdata, MDD, Zoonomia, VertLife, GEBCO, PROJ, Pleiades and RCSB PDB. Links identify provenance candidates; the integration does not imply that these datasets have been copied or loaded.
