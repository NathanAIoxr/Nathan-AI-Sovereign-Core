## Programmatically generated relationship layer

The [source-locked engine](engine.js) computes character-edit distance between original forms, using separate metadata labeled `algorithmic-form-comparison`. It supports:

- Exact positions versus distinct name counts
- Searchable authored spellings
- Labeled graph links (1–5 character edits) and deterministic node identifiers
- Explicit P-r-to-B initial transformations where they match an actual original
- Observed d/t and single-i changes
- Reversed spelling
- User-owned JSON export with original occurrences isolated from machine-generated proposals

Derived forms are **not** silently attributed to the creator. Proposed meaning, word origin, or cultural connections require evidence and author review through the [Nathan AI Completion Engine](../completion-engine/index.html).

The A/V graphical comparison is a visual heuristic. Rotating A upside down resembles the symbol ∀, rather than establishing that A and V are identical glyphs in all scripts. Grapheme comparisons, typography and historical etymology must be kept distinct.
