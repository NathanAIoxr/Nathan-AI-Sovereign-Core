```bash

DB=/owner/private/ONE_Federation_Master.sqlite3

python3 "$F/specialist_bees.py" --db "$DB" roles
python3 "$F/specialist_bees.py" --db "$DB" status
python3 "$F/specialist_bees.py" --db "$DB" --approve-write --owner-yes seed
python3 "$F/specialist_bees.py" --db "$DB" --approve-write --owner-yes demo
python3 "$F/specialist_bees.py" --db "$DB" status
```

`seed` explicitly allocates 25 separate sovereign identities within the original 256 locally allocated bee limit (seasonal hive ordinals 101–125), assigns their specialization and creates a source provenance lock. `demo` additionally executes 25 individually approved deterministic tasks. Both require `--approve-write --owner-yes`.

In ordinary operation, use `--bee`, `--role`, `--task`, `--text` with `propose`, `approve`, `execute`, `veto`, or `inspect` and retain the original bee's veto and source. Task results are stored in the current ONE SQLite file only. Use the actual owner-held database path for persistent local data; GitHub CI does not have it.
