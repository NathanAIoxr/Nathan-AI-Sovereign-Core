# Nathan AI — source and completion rules

Creator directive, preserved verbatim:

> start completeing projects to 100% perfection 100% my words and tone and 100% compliance - go forth and build it out

1. Preserve original words, titles, terminology, source files and architecture. Add new work alongside them.
2. Keep exact creator text separate from new implementation, editorial writing and test fixtures.
3. Keep original source status and completion requirements unchanged. Review evidence belongs in a separate record.
4. Record the original source, word/tone check, dependencies, behavior/output verification and original acceptance result for each project.
5. Keep missing evidence visible. A blank required check keeps completion open.
6. Verify saved work and backups. Match them to the source catalog before restoring them.
7. Keep private original material owner-controlled. Public coordination tools and aggregate reports remain separate.

The workbench records evidence supplied by its operator. Each project's actual completion still requires the stated tests and source review. This tool does not certify every project complete or guarantee absolute perfection.
