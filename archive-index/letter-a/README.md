## Classification rule

A title beginning with A is different from an A reference buried inside another title. Project, application, game, book, technical concept, language, cultural term, fictional character, mythological figure, and historical reference remain separately classified in their **original collection**. Repeated title strings across collections are not silently deduplicated. Likewise, alternate spellings or mirrored words are **derived search views**, not substitutions for originals.

**User-authored chain examples:** `RA ↔ AR`, `AARGH`, `AAR-001 → ALL AUTHORITY REVERSAL PROTOCOL`, `ABLE / ELBA / ACT / TCA`, `Ankh-Æ`, and the other A chains named in the variation matrix. Their exact source meanings require the matching originals; the index does not invent meanings.

**Implementation truth:** A catalog row is not proof a feature runs. The source file and current repository module determine verified implementation status. Source catalog rows often explicitly say the original body is **not established** and derivative rewrite is **not authorized by default**.
