## Nathan's original D geometry — exact wording

> pull up all things that start with D .. an O that ran into the back of a stopped rock ... a tomb when you rock it over to the flat side

> keep digging - find all the D's - the dicks, the ddd's the dd's and all inversions

Separate these operations:

- **Text reversal:** `dick → kcid`; `dicks → skcid`; `DDD → DDD`.
- **Visual mirror:** `D → ᗡ` (illustrative shape); `d ↔ b` may resemble horizontal mirroring depending on font.
- **Vertical flip / half-turn:** `d ↔ q` or `d ↔ p` can be approximate glyph-shape candidates; **not** automatic language or source identity.
- **Substitution:** Latin alphabet Atbash `D → W`; ROT13 `D → Q`.
- **Numeric conventions:** fourth Latin letter D; Roman numeral D=500; ASCII uppercase D=68, lowercase d=100. Do not collapse these systems.

No standalone exact DD or reversed Dick/dicks *source hit* was established in the previous recovery. Generated reversals here are labeled derivatives rather than falsely reported as recovered originals.
