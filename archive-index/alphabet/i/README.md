# Nathan AI — I · Source-Preserving Alphabet Department

This is the **I** department of the full 26-letter A–Z directory. It currently contains **23 separate source-catalog occurrences**, indexed with source status, source provenance, App/Game classification proposals and preserved original source wording.

- [Open I search, app and game categories](../index.html?letter=I)
- [See this department's source ID manifest](./letter-manifest.json)

**Preservation:** This department is a new index over existing independent apps, game references, author sequences and source inventories, not a new invented manuscript, finished software release, or replacement for an original. Original categories and title-initial letters can differ; the two are separate properties.

**Store classes:** proposals only. Apple allows primary/secondary categories; Google Play uses one category plus at most five approved tags. Unknown categories remain unset until reviewed. Real mobile submission, rights and age-rating requirements are separate tasks.
