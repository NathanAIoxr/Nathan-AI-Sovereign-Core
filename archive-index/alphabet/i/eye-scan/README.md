# Nathan AI — I / EYES / GHG · Text Scan Sidecar

Creator: Nathan Tabor. **Additive, source-preserving**. Neither the existing 23 I catalog occurrences nor the original I/Soul Eyes author language is overwritten.

## What is here
- `engine.js`: works on **explicitly provided text** with literal character reversal, typographic inversion, palindromes, acrostics, names, and context-tagged matches.
- `engine.test.cjs`: isolated tests for GHG, EYE, THC / CHT, CPT / TPC, and historical alias separation.
- `index.html`: a local-only input and results interface.
- No private Library originals are copied to the public repository.

## GHG / “ghensis Chon” / Confucius
- **GHG** is the author's upside-down EYE cipher reading; typography and mathematical rotation are separate.
- The user's phonetic name **“ghensis Chon”** is cross-referenced to **Genghis / Chinggis Khan**, birth name **Temüjin**, who died in **1227 CE**. This is **not** an attested historical spelling.
- **Confucius**, also called **Kongzi** or **Kong Fuzi**, lived **551–479 BCE**, many centuries earlier. **Analects 2.10** examines actions, motives, and where a person rests content.
- Conceptual crosswalk: historical information relays and reconnaissance → careful observation and context → source-preserving text search. This is not a secret historical connection.
