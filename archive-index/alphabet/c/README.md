Read [routes.json](./routes.json) for the detailed evidence criteria; [c-family.mjs](./c-family.mjs) implements read-only text discovery.

1. Literal C/c names and repetitions C/CC/CCC.
2. The C and numbered C title families.
3. Phonetic variants C / see / sea / cee / si, linked for review **without silently replacing spellings**.
4. Hard C, soft C and digraphs (ch, ck, sc) — word- and language-specific.
5. Reversal by exact code-point order: `CIPHER → REHPIC`; `CHRISTMAS → SAMTSIRHC`; a reversed string is not automatically a dictionary word.
6. Reflected C glyphs, circled symbols and cross-script glyphs. A visual lookalike is not proof of shared origin or pronunciation.
7. Chemical `C` = carbon (atomic number 6), `Cu` = copper (atomic number 29); Roman `C` = 100; standard alphabet C is the third letter; ASCII uppercase `C` = 67 — separate measurement systems.
8. C programming, C++ and C#, music's Middle C, and creator-symbolic Middle C — related by labels but remain independent objects.

**C the alphabet letter is not the same category as local subject shelf C**, or as `C` used in music, chemistry, computer code, Roman numerals or physics.
