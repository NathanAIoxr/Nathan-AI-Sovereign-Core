Store classification is a proposal, not a publication

Apple allows a primary and optional secondary app category, and game subcategories. Google Play uses one app or game category and a maximum of five chosen tags. The local directory records suggested categories only when the name or source provides an identifiable subject. It never claims an app has passed Apple review, appeared on Google Play or been compiled for a phone.

Earlier A, B, C, D, and E word-family modules stay independent. Book titles, word meanings, historical references, source-code components and privately held originals are not automatically treated as finished apps. Unpublished originals and restricted source bytes are not copied into this public directory.
