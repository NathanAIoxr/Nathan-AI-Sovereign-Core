## KRISTIAN Plaque Archive

Nathan Tabor’s plaque, corrected wording, and a record of the edits.

Public app: https://unified-operations-cockpit.nathantaboract.workers.dev/tabor-apps/kristian-plaque/

The manifest, service worker, and icons are served from the application’s own URL scope. Cloudflare Workers for Platforms runs this app as `kristian-plaque-app`.

Run `node standalone-apps/tabor-app-runtime/verify.mjs kristian-plaque local` to verify the build. Use `live` to check the deployed app.
