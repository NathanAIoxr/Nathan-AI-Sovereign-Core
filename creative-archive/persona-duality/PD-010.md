# PD-010 — Authorship and graph boundary checks

This test suite verifies that the public Persona Atlas does not silently collapse scripture, folklore, original fictional characters, spelling variants, or software agent roles into identical identities. The tests enforce typed graph nodes, existing endpoint integrity, read-only integrations, and the distinction between scheduled review and completed execution.

Run: `node --test creative-archive/persona-duality/worker.test.mjs creative-archive/persona-duality/authorship-boundaries.test.mjs`

Scope: checks only the existing public registry and runtime. These tests **do not authenticate the historic authorship of a claim**; that requires source-linked review in PD-001/PD-002. Do not infer third-party IP ownership or publish private source assets.

No existing canon or Cloudflare Worker code is changed in this PR.
